مكتبة مهارات Claude

مهارات جاهزة لـ Claude Code: تعطيه الطلب بجملة، وهو يمشي على تعليمات مكتوبة له. انسخها لجهازك مرة وحدة.

افتح المستودع على GitHub

كيف تنسخها لجهازك

١نزّل المستودع

افتح الطرفية (Terminal) واكتب:

git clone https://github.com/ahmadalobaid2020-a11y/my-claude-skills.git

٢انسخ المهارات لمكان Claude

هذا السطر ينسخ مجلد المهارات للمكان اللي يقرا منه Claude Code:

mkdir -p ~/.claude/skills && cp -r my-claude-skills/skills/* ~/.claude/skills/

٣جرّب

افتح Claude Code من جديد، واكتب طلبك بالكلام. مثلاً: «حط ترجمة عربي على هالفيديو».

فيه ملف اسمه install.sh يثبّت كل شي مع بعض، ومعه أدوات إضافية بعضها حجمه كبير (عدة جيجابايت). اقرا الملف قبل ما تشغّله، أو اكتفِ بالخطوتين فوق.

أمثلة من المهارات

  • subtitles: ترجمة للفيديو، عربي أو إنجليزي، وتثبيتها عليه.
  • video-shorts: قص مقاطع عمودية قصيرة من فيديو طويل.
  • thumbnail: صورة مصغّرة ليوتيوب بخط عربي.
  • youtube-seo: عنوان ووصف ووسوم من نص الفيديو.
  • audio-cleanup: تنظيف الصوت وضبط مستواه.

القائمة الكاملة في صفحة المستودع.
