# صيّاد البريد

عرض تقديمي تفاعلي بالعربي عن التوعية بالتصيّد الإلكتروني، في ملف HTML واحد. افتح `index.html` في أي متصفح.

النسخة المنشورة: https://claude.ai/artifact/KXpL1SBhzTa5JC932w2eF8

## الشرائح

1. **الافتتاحية:** شاشة جوال توصلها إشعارات، وصنارة تنزل عليها.
2. **تشريح رسالة:** إيميل مزيّف فيه 5 علامات خطر، والمشاهد يضغط على كل علامة يكتشفها.
3. **فاحص الروابط:** يلوّن النطاق المسجَّل ويقول وين يوديك الرابط فعلاً.
4. **محاكاة الهجوم:** خط زمني لأربع دقائق مع تشغيل وإيقاف ومنزلق سرعة، وزر «توقّف وتحقّق».
5. **اختبار:** أربع رسائل، احتيال أو سليمة، مع الشرح والنتيجة.
6. **خطة الاستجابة:** خمس خطوات لمن ضغط على الرابط.
7. **الخلاصة:** ثلاث قواعد، و«فكّر قبل أن تضغط».

التنقل بأسهم الكيبورد أو الأزرار. أسماء البنك والنطاقات كلها مخترعة.

## برومبت لإعادة إنتاج عرض مشابه

```
سوّ لي عرض تقديمي تفاعلي كصفحة HTML واحدة (بدون PowerPoint)، باللغة العربية واتجاه من اليمين لليسار.

الموضوع: [اكتب الموضوع هنا، مثلاً: التوعية بالتصيّد الإلكتروني]
الجمهور: [مثلاً: موظفون غير تقنيين]
عدد الشرائح: [مثلاً: 7]

المطلوب:
- كل شريحة فيها عنصر تفاعلي يجربه الحضور بأنفسهم، مو نص فقط: أزرار، منزلقات، اختبار، محاكاة.
- شريحة واحدة على الأقل فيها محاكاة متحركة على خط زمني، مع تشغيل وإيقاف ومنزلق للتحكم بالسرعة، وأرقام تتحدث مباشرة أثناء التشغيل.
- شريحة اختبار يحكم فيها المشاهد على أمثلة، ويطلع له شرح وسبب بعد كل إجابة، مع عداد للنتيجة.
- تنقل بأسهم الكيبورد وأزرار التالي والسابق، ومؤشر لرقم الشريحة، وزر ملء الشاشة.
- شاشة 16:9 على الكمبيوتر، وتشتغل على الجوال.
- تصميم احترافي بخطوط عربية واضحة، ويدعم الوضع الفاتح والداكن.
- محتوى حقيقي ودقيق، والأسماء والأمثلة مخترعة بدون علامات تجارية حقيقية.
- كل الكود في ملف واحد، وكل الأزرار تشتغل فعلاً بدون أي جزء ناقص.

قبل ما تكتب الكود، اقترح لي محتوى كل شريحة والعنصر التفاعلي فيها، وبعدها نفّذ.
```
