# صيّاد الأشكال

فيديو أطفال تفاعلي بالعربي (9:16، 35 ثانية): روبو يسأل الطفل عن ثلاثة أشكال، عدّ تنازلي ٣ ٢ ١، ثم يكشف الجواب (دائرة، مثلث، مربع)، ويختم بالنجمة.

- `index.html`: العرض بحركة مبرمجة (مهارة `bang-motion`): الكاميرا تتنقل يمين، فوق، قُطرياً مع لفّة كاملة، ثم تحت. يشتغل تلقائياً ويتكرر؛ `?debug=1` يظهر شريط تمرير.
- `assets/a..e.webm`: خمس لقطات مولّدة بـ Seedance 2.0 mini (720p) لشخصية واحدة ثابتة، معروضة داخل إطارات على شكل الجواب.
- `assets/audio.mp3`: تعليق سعودي (ElevenLabs، صوت «Abir - Arabic Female»، `eleven_v4`) مع مؤثرات عدّ وكشف مصنوعة بـ ffmpeg. بدون موسيقى.
- `shapes-hunt.mp4`: النسخة النهائية 1080×1920 بمعدل 30 إطار.
